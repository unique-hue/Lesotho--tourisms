# Lesotho Tourism Website

Student project for Web Design (BIWD2110), Assignment 1.

## Preview the website on your computer
1. Extract the `lesotho-website-ready.zip` file.
2. Open the `lesotho` folder.
3. Double-click `index.html` (or right-click and choose a browser).
4. Use the navigation menu to visit Destinations, Accommodation, Activities, Gallery and Contact / Book.

Keep the `css`, `js` and `images` folders beside the HTML files. Do not move individual files out of the project folder.

## Publish it free with GitHub Pages
1. Sign in at https://github.com/ or create an account.
2. Select **New repository**.
3. Name it `lesotho-tourism` and set it to **Public**.
4. Create the repository.
5. Select **Add file → Upload files**.
6. Upload the contents of this project folder, so `index.html` is at the repository's top level (alongside `destinations.html`, `css/`, `js/` and `images/`). Do not upload only the ZIP file.
7. Select **Commit changes**.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Choose branch **main** and folder **/(root)**, then select **Save**.
11. Wait a minute or two, then refresh the Pages screen. GitHub will show your public website address, usually `https://YOUR-USERNAME.github.io/lesotho-tourism/`.

If the page does not load, check that the file is named exactly `index.html` and is in the repository root. GitHub Pages needs the HTML files and the `css`, `js` and `images` folders uploaded with their folder structure intact.

## Pages
- `index.html` - Home
- `destinations.html` - Destinations
- `accommodation.html` - Accommodation
- `activities.html` - Activities
- `gallery.html` - Photo gallery
- `contact.html` - Contact and booking

## Project assets
- `css/style.css` - custom styles
- `js/script.js` - JavaScript features
- `images/` - website images

The site uses Bootstrap 5.3 from a CDN, so an internet connection is needed for Bootstrap styling and components.
